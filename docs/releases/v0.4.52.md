# Relay Runner 0.4.52

## More reliable voice recovery

- Voice commands that cannot be acknowledged now show an actionable recovery notice instead of waiting indefinitely.
- Safely skip an uncertain message or confirm a session restart while preserving queued requests. Uncertain commands are not automatically replayed.
- Improved terminal submission ordering so queued messages submit without an extra Return press.
- Fixed stale speech cancellation leaving “Preparing speech” stuck, while protecting newer replies from old cleanup events.

## Clearer research outcomes

- Research work now requires explicit execution mode and required inputs before dispatch.
- Incomplete implementation notifications explain the failure while preserving access to research findings.

Codex skip and restart recovery, audible queued replies, and speech-overlay cleanup passed installed-app testing. Claude live recovery verification was excluded from this release's acceptance scope; shared automated provider coverage remains in place.

Requires macOS 14 or later.
